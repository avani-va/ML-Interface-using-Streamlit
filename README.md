# 🤖 Machine Learning Analysis Dashboard

An interactive **Machine Learning Analysis Dashboard** built using **Python and Streamlit**. The application allows users to explore datasets and perform classification using **Support Vector Machine (SVM)** and **Random Forest Classifier**.

## 📌 Project Overview

This project demonstrates the practical implementation of supervised machine learning algorithms through an interactive web-based dashboard.

The application provides users with the option to select different machine learning models and visualize their performance using evaluation metrics and graphical representations.

### Machine Learning Models Used

- 🔵 **Support Vector Machine (SVM)**
- 🌳 **Random Forest Classifier**

## ✨ Features

- 📊 Interactive Streamlit dashboard
- 📁 Dataset analysis and exploration
- 🤖 Support Vector Machine classification
- 🌳 Random Forest classification
- 📈 Model performance evaluation
- 🔢 Confusion Matrix visualization
- 📉 Data visualization using graphs
- 🧩 Easy-to-use interface
- 📚 Educational explanations of the ML algorithms

## 🧠 Algorithms

### 1. Support Vector Machine (SVM)

SVM is a supervised machine learning algorithm that finds the best boundary (hyperplane) to separate different classes of data.

It is particularly useful for classification problems where the classes need to be separated effectively.

### 2. Random Forest Classifier

Random Forest is an ensemble learning algorithm that combines multiple decision trees to make a more accurate and reliable prediction.

Instead of relying on a single decision tree, Random Forest uses multiple trees and combines their predictions.
